# CV Writing Skill

Professional CV / resume standards gathered and cross-verified from current (2025-2026) career advice, ATS-optimization guides, and recruiter research. Goal: a document that (1) parses cleanly through Applicant Tracking Systems (ATS), and (2) reads clearly to a human in a 6-7 second first scan.

## Two readers, one document
- MACHINE (ATS: Workday, Greenhouse, Lever, iCIMS). Parses top-to-bottom, left-to-right, extracts text into fields. Rewards clean structure, standard fonts, no visual noise.
- HUMAN (recruiter). Scans ~6-7 seconds for the job title and the biggest achievement. Rewards clear visual hierarchy and strategic white space.

The classic mistake is optimizing for one reader and losing the other: over-embellished documents fail ATS; bare text repels humans. Serve both.

## Formatting spec (baseline)
Use these values unless industry/region norms say otherwise.

| Setting | Spec |
|---|---|
| Body font | Calibri, Arial, Helvetica, Cambria, Garamond, Georgia (serif for academia/law). IBM Plex Sans / Lato / Open Sans for tech/creative. |
| Body text size | 10-11 pt — NEVER below 10 pt |
| Name | 14-18 pt bold (executives up to 18-20) |
| Section headings | 12-14 pt bold, ALL-CAPS optional |
| Margins | 0.5-1.0 in, consistent on all 4 sides. Sweet spot 0.5-0.75. Never below 0.5. |
| Line spacing | 1.0-1.15 |
| Space between sections | 12-16 pt (more above a heading than below) |
| Space between roles | 6-10 pt |
| Space after bullets | 2-4 pt |
| Columns | SINGLE column only — two-column drops ATS parse accuracy to 40-60% |
| File format | PDF unless posting requests DOCX. Never image formats. |

### Calibration by career stage
- Entry-level: 1 page, name 14-16pt, margins 0.75-1.0in, Calibri.
- Mid-career (3-10 yr): 1-2 pages, margins 0.5-0.75in.
- Senior/executive: 2-3 pages, name 16-20pt, Garamond/Cambria often apt.
- Career changer: 1 page, transferable-skills focus.
- Academic CV: serif (Garamond/Cambria/Times New Roman), 2-5+ pages.

## Visual hierarchy
Name (largest, bold) > Section headings (medium, bold) > Job title + company > Bullets (body) > Contact (smallest).
- Bold job titles + section headings. Italic sparingly (companies/dates). NEVER underline.
- Formatting must be identical across every role entry; right-align dates consistently.
- One accent color max (navy #1B3A5C, dark teal #1A6B5E, charcoal #333, burgundy #722F37, forest #2E5C3E) for headings/dividers only, never body text. Conservative fields: black & white. Never convey info only via color.

## Section order (lead with strongest asset; open with a summary)
- Entry-grad: Contact → Summary → Education → Projects/Internship → Skills → Certs.
- Mid-career: Contact → Professional Summary → Work Experience → Skills → Education → Certs.
- Senior/exec: Contact → Executive Summary → Key Achievements (opt.) → Work Experience → Education → Board/Publications.
- Career changer: Contact → Summary (transferable) → Relevant Experience (reframed) → Transferable Skills → Education/Training.

## Contact header (ATS-critical)
- Put name + contact in the DOCUMENT BODY at top, regular text, NOT a Word header/footer (ATS skips headers).
- Line 1: name. Line 2: email | phone | LinkedIn | city. Skip full postal address.

## ATS safe vs risky vs breaking
SAFE: single column, standard fonts, round bullets, horizontal dividers, left-aligned bold/italic text, PDF/DOCX.
RISKY: multi-column, headers/footers, text boxes, tables used for layout, icons/symbols, infographics, embedded images/headshots.
BREAKING: image-based CVs (Canva exports), PNG/JPG submission, graphics/text-box-heavy templates, watermarked templates.
- Photo: omit for US (bias); expected in EU/Asia/Latin America.
- Plain-text test: paste into Notepad — if order is preserved, it parses cleanly.

## Achievement bullets — the core craft (XYZ / action verb + task + quantified result)
Every bullet opens with a strong action verb and ends with measurable impact. Duties are weak; proof wins.

Action verbs:
- Leadership: led, directed, spearheaded, drove, launched, established, founded, scaled, mentored.
- Achievement: increased, improved, reduced, grew, accelerated, generated, saved, delivered.
- Tech/analysis: built, engineered, designed, developed, automated, architected, analyzed, optimized.
- Communication: negotiated, presented, persuaded, collaborated, authored, published, trained, taught.

Quantification: %, count, time saved, headcount, revenue. No hard metrics? Use scope/scale: "led team of N", "managed NA budget", "served N clients", "cut turnaround X→Y days". Every bullet = verb + task + outcome.

## Skills section
- Hard + soft skills mirroring the job description phrasing exactly (ATS matches phrases).
- Comma-separated keywords or plain bullets. Never skill bar charts/stars. e.g. "Python (Advanced), Spanish (Conversational)".

## Keywords / tailoring
- Tailor to the target job posting, never a generic document.
- Weave in the posting's exact tools, skills, certs, and keywords inside the bullet context (not stuffing).
- Include the posting's job title + key competencies to raise match score.

## Resume vs CV and regions
- US/Canada: resume = 1-2 page; CV = long academic doc (publications, talks, teaching, awards, grants) for faculty/grad/research, 2-5+ pages, serif, dense.
- Europe/most of the world: "CV" is the standard 1-2 page job document.
- US: no photo. EU/Asia/LatAm: photo common. Confirm the target market.

## Industry norms
- Finance/Law/Gov/Healthcare: conservative B/W, serif or clean sans, single column, no graphics.
- Tech/startups: sans (Calibri/Inter/IBM Plex/Lato), subtle accent, skills prominent.
- Creative: more liberty — keep posting keywords; test ATS; make a "designed" version for networking and a "clean" version for online apps.

## Workflow
1. Clarify role, level, industry, target region; ask for the job description when possible.
2. Gather education, work history (real achievements + metrics), skills, certs, projects, publications.
3. Pick format spec + section order per tables above.
4. Draft: contact header, summary paragraph, achievement bullets (XYZ + quantification), skills mirroring the JD.
5. Review: ATS checklist (single column, fonts, no tables/headers, plain-text test), consistency, no underlines, metrics present.
6. Output a plain-text single-column resume to drop into a template; recommend PDF export. Flag any ATS-risky elements.
